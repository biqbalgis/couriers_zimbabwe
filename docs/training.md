# Pano Logistics Role Training Guide

Version 1.1 · 1 October 2026 · Mutare–Chipinge pilot

## Every participant

Use your own account. Keep passwords, verification codes and recipient secret links private. Confirm the parcel's six-digit shipment code and inspect the physical parcel before sharing a handover code. The handover code expires after fifteen minutes and locks after five attempts; an active code cannot be regenerated. Offline capture does not prove that the server accepted custody.

## Sender and recipient

1. Sender: sign in, choose the pilot direction/stations, add recipient phone in +263 format, weight band and a clear photo. Add a pickup address only if collection is needed.
2. Check the quoted USD amount and confirm the booking. Pay the actual origin station number outside the app; upload a receipt. Operations verifies it before dispatch.
3. Use parcel details to follow events and share the secret tracking link only with the recipient.
4. Recipient: choose station collection or a real home address before delivery starts. Generate the receiving code only with the parcel in front of you. Inspect it before giving the code to the station or rider.
5. Report a problem through support. Use the configured phone/helpdesk link for a call or guest contact. After-hours reports wait until the next 08:00 opening. Contact staff for refunds; the application does not refund automatically.

## Station operator

Book a walk-in parcel from your own station using the customer's name and phone, not your staff identity. Confirm payment numbers and receipt amount. On receipt, request the next code from the current custodian, check the shipment and confirm the station handover. Carrier/rider collection is confirmed by the receiving worker, not by marking the station release as a delivery. At destination, hold the parcel safely until self-collection or an accepted local-rider pickup. Obtain the recipient receiving code before confirming self-collection.

## Local rider

Apply with an identity/operating document and home station; wait for approval, then set availability. Review and accept the assigned pickup/delivery offer. For first-mile pickup obtain the sender's code; origin staff confirm arrival. For last mile obtain the destination station's releasing code, then the recipient's final receiving code. Capture a delivery photo and signature. Check Offline sync until queued work is accepted; if the code expires, obtain a fresh code and capture a new submission rather than editing an already-used retry key. Earnings and statements are allocations/recorded external payments, not a wallet balance.

## Inter-town carrier

Apply with identity, licence/vehicle documentation and capacity. After approval schedule the correct route and future departure. Accept offered route work; do not load beyond verified remaining capacity. Obtain the origin custodian's code and record departure. Destination staff confirm receipt using your releasing-party code. Your accepted route task remains active until destination receipt.

## Operations and finance

Vet actual identity/vehicle documents before approval. Match riders by town and requested leg, carriers by scheduled route/capacity. Verify receipt against the booked amount before dispatch. Do not bypass requested pickup, custody states or proof requirements.

For a delivered, verified parcel allocate first-mile rider, last-mile rider, carrier and origin-station amounts. Enter zero for unused legs; the platform receives the remainder. Rider beneficiaries are the workers who completed each leg. Review and approve allocations, make the payments externally, then record real references. Download statements and CSV and reconcile with the payment channel. Never record paid just to clear the dashboard.

## Support and administrator

Use the chosen SaaS helpdesk/telephony system for live calls/chats. The local support companion captures issues, lookup and conversation updates for the bridge; it does not replace telephony. Work 08:00–20:00 Harare time according to the approved roster; handle overnight contacts from the next opening. Escalate custody/payment discrepancies with parcel code and evidence. Administrators maintain accounts, pilot route and configuration without sharing secrets in the browser.

## Feedback and learning log

After consented pilot journeys ask senders/recipients and carriers whether booking, custody, delivery and payment instructions were clear. Capture rating, comments and actionable issues through the operator's approved survey/helpdesk; no dedicated feedback table is implemented. Avoid recording unnecessary phone/identity details in shared documents.
